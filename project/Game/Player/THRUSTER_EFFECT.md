# プレイヤー・スラスター光

## 実装場所

- `BoosterEffect.cpp`：左右ノズルの位置、色、速度に応じた炎の長さ・太さ・明るさを決めます。白い発光コア（球）と青い外炎（円すい）もここで作成します。
- `Player.cpp`：プレイヤー位置・姿勢・加速入力を毎フレーム `BoosterEffect` へ渡します。また、発光を加算合成で描画します。
- `GamePlayScene.cpp`：実際に使用中のカメラを `Player::Draw` に渡します。スラスターの帯はカメラ正面を向くため、このカメラが必須です。
- `Trail.cpp`：現在位置の履歴から、カメラへ正面を向けた細長い三角形ストリップを作ります。

## 見た目の作り方

1. 機体のローカル座標で左右のノズル位置を指定します。ゲームの移動前方は `+Z`、ノズルと噴射方向はカメラ側の `-Z` です。
2. 機体のクォータニオンを使ってその位置をワールド座標へ回転・移動し、プレイヤーの後方へ追従させます。
3. ノズルに白い球の発光コアと、後方へ伸びる青い円すいを常時描画します。停止中でもここは必ず見えます。
4. 毎フレームのノズル位置を履歴に蓄積して、加速時だけ細い先端から後方へ広がるリボン状の余韻を作ります。
5. 移動速度と前進入力に比例して、外炎の長さ・太さ・アルファ値を滑らかに変化させます。
6. 加算合成（`SrcAlpha + One`）で描画し、宇宙背景でも光として目立たせます。ノズル直後の球と外炎は深度テストなし、トレイルは通常の深度テストありで描き分けています。これにより、機体・地形に隠れた角度でもノズル光だけは消えません。

## 調整する値

`BoosterEffect.cpp` の `SetupBurnersForMode` にある `offset` がノズル位置、`defaultScale` が基準サイズ、`color` が炎の色です。`Update` 内の `targetScaleZ` と `targetAlpha` を上げると、加速時の炎をより長く明るくできます。
